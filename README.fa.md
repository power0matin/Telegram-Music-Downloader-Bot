## 🚀 شروع سریع

### گزینه ۱: نصب خودکار (پیشنهادی)

```bash
# کلون کردن مخزن
git clone https://github.com/your-username/spotify-downloader-bot.git
cd spotify-downloader-bot

# اجرای اسکریپت نصب خودکار
./setup_bot.sh
```

### گزینه ۲: نصب دستی

<details>
<summary>برای مشاهده راهنمای نصب دستی کلیک کنید</summary>

```bash
# کلون کردن مخزن
git clone https://github.com/your-username/spotify-downloader-bot.git
cd spotify-downloader-bot

# ایجاد و فعال‌سازی محیط مجازی
python3 -m venv venv
source venv/bin/activate  # لینوکس/مک
# یا: venv\Scripts\activate  # ویندوز

# نصب وابستگی‌ها
pip install -r requirements.txt

# تنظیم توکن ربات
cp .env.example .env
# فایل .env را ویرایش کرده و توکن ربات خود را اضافه کنید

# شروع ربات
./start_bot.sh
```

</details>

## 📖 راهنمای کامل نصب و راه‌اندازی

### مرحله ۱: پیش‌نیازها

قبل از شروع، مطمئن شوید که موارد زیر را دارید:

- **پایتون ۳.۸ یا بالاتر** نصب شده روی سیستم
- **Git** برای کلون کردن مخزن
- **اتصال اینترنت** برای دانلود وابستگی‌ها
- **اکانت تلگرام** برای ایجاد ربات

### مرحله ۲: دریافت توکن ربات تلگرام

1. **تلگرام را باز کنید** و `@BotFather` را جستجو کنید
2. **چت را شروع کنید** و `/newbot` ارسال کنید
3. **نامی برای ربات انتخاب کنید** (مثال: "ربات موزیک من")
4. **نام کاربری انتخاب کنید** (باید به 'bot' ختم شود، مثال: "my_music_downloader_bot")
5. **توکنی که BotFather می‌دهد را کپی کنید** (فرمت: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)
6. **این توکن را امن نگه دارید** - هرگز آن را عمومی نکنید!

### مرحله ۳: کلون و راه‌اندازی

```bash
# کلون کردن مخزن
git clone https://github.com/your-username/spotify-downloader-bot.git
cd spotify-downloader-bot

# قابل اجرا کردن اسکریپت نصب
chmod +x setup_bot.sh

# اجرای نصب خودکار
./setup_bot.sh
```

اسکریپت نصب این کارها را انجام می‌دهد:
- ✅ بررسی نیازمندی‌های سیستم
- ✅ نصب وابستگی‌های سیستم (FFmpeg و...)
- ✅ ایجاد محیط مجازی پایتون
- ✅ نصب پکیج‌های پایتون
- ✅ ایجاد فایل‌های تنظیمات
- ✅ راه‌اندازی ساختار دایرکتوری
- ✅ تأیید نصب

### مرحله ۴: تنظیم توکن ربات

در طول نصب، از شما برای وارد کردن توکن ربات درخواست می‌شود. همچنین می‌توانید دستی تنظیم کنید:

```bash
# ویرایش فایل .env
nano .env

# اضافه کردن توکن
BOT_TOKEN=your_telegram_bot_token_here
```

### مرحله ۵: شروع ربات

```bash
# شروع ربات
./start_bot.sh
```

باید این پیام را ببینید:
```
🤖 Starting Spotify Downloader Bot...
Bot is running...
```

### مرحله ۶: تست ربات

1. **ربات خود را در تلگرام پیدا کنید** (نام کاربری که ایجاد کردید را جستجو کنید)
2. **`/start` ارسال کنید** تا شروع کنید
3. **لینک اسپاتیفای ارسال کنید** (مثال: `https://open.spotify.com/track/...`)
4. **کیفیت را با دکمه‌ها انتخاب کنید**
5. **موزیک خود را دریافت کنید!** 🎵

## 🔧 رفع مشکلات

### مشکلات رایج و راه‌حل‌ها

<details>
<summary><strong>🚫 "No module named 'telebot'"</strong></summary>

**مشکل**: وابستگی‌های پایتون نصب نشده یا محیط مجازی فعال نیست.

**راه‌حل**:
```bash
# فعال‌سازی محیط مجازی
source venv/bin/activate

# نصب وابستگی‌ها
pip install -r requirements.txt
```

</details>

<details>
<summary><strong>🚫 "BOT_TOKEN not set"</strong></summary>

**مشکل**: توکن ربات تلگرام تنظیم نشده.

**راه‌حل**:
```bash
# ویرایش فایل .env
nano .env

# اضافه کردن توکن
BOT_TOKEN=your_actual_bot_token_here
```

</details>

<details>
<summary><strong>🚫 "FFmpeg not found"</strong></summary>

**مشکل**: FFmpeg روی سیستم نصب نشده.

**راه‌حل**:
```bash
# اوبونتو/دبیان
sudo apt update && sudo apt install ffmpeg

# سنت او اس/ردهت
sudo yum install ffmpeg

# مک او اس
brew install ffmpeg

# یا دوباره اسکریپت نصب را اجرا کنید
./setup_bot.sh
```

</details>

<details>
<summary><strong>🚫 "Permission denied" برای اسکریپت‌ها</strong></summary>

**مشکل**: اسکریپت‌ها مجوز اجرا ندارند.

**راه‌حل**:
```bash
chmod +x setup_bot.sh
chmod +x start_bot.sh
```

</details>

<details>
<summary><strong>🚫 شکست در دانلود</strong></summary>

**مشکل**: دانلودها با شکست مواجه می‌شوند یا timeout میکنند.

**راه‌حل‌ها**:
- ✅ اتصال اینترنت را بررسی کنید
- ✅ مطمئن شوید لینک اسپاتیفای صحیح و عمومی است
- ✅ چند دقیقه صبر کنید (محدودیت نرخ)
- ✅ آهنگ/آلبوم دیگری امتحان کنید
- ✅ بررسی کنید که محتوا محدودیت جغرافیایی ندارد

</details>

## ⚙️ تنظیمات

### متغیرهای محیطی

فایل `.env` را برای سفارشی‌سازی ویرایش کنید:

```env
# اجباری: توکن ربات تلگرام شما
BOT_TOKEN=your_telegram_bot_token_here

# اختیاری: کیفیت پیش‌فرض (128 یا 320)
DEFAULT_QUALITY=320

# اختیاری: حداکثر تلاش مجدد برای دانلود
MAX_RETRIES=5

# اختیاری: تأخیر تلاش مجدد به ثانیه
RETRY_DELAY=5
```

### تنظیمات پیشرفته

فایل `config.py` را برای تنظیمات پیشرفته ویرایش کنید:
- دایرکتوری‌های دانلود
- تنظیمات timeout
- رفتار مدیریت خطا
- مدیریت صف
